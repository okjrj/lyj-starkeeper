# 별 관리인의 하루

기존 애니메이션 세계관을 바탕으로 만든 웹캠 인터랙션 체험. 체험자는 밤마다 해에서 빛을 떼어 별에 넣고 하늘에 거는 별 관리인이 된다. 몸짓으로 일과를 수행한 뒤 자신이 만든 별자리를 올려다본다.

> 상관없던 하늘이, 내가 바라보는 하늘이 되기까지.

무심히 지나치던 하늘을 잠시 멈춰 바라보게 만드는 것이 기획 의도다. 웹캠 1대와 MediaPipe를 사용하며, 손 동작을 중심으로 진행한다. 얼굴 동작은 후속 장면에서 검토할 수 있다.

## 현재 구현된 흐름

타이틀에서 방을 탐색하고, 창가에서 해를 가져와 별박스를 밝힌 뒤 바구니에 별을 담는다. 사다리를 올라 별 세 개를 걸고 달에 도착하면 원본 영상 또는 바로 끝내기를 선택할 수 있다. 장면별 구현과 대화에서 결정한 흐름은 [작업 인수인계](인수인계.md)에 정리되어 있다.

## 유지할 조작과 UI

- 손 장갑을 대상에 올리고 **주먹을 쥐었다가 펴면** 클릭된다. 마우스 클릭도 가능하다. 방 안 오브제는 손이나 마우스를 가져갔을 때 그림 윤곽에 맞춰 빛난다.
- 버튼을 선택하거나 가이드와 메모장이 열릴 때 짧은 차임이 울린다.
- 타이틀의 흰색 UI와 읽기 쉬운 글꼴, 가로 화면에서 구름과 겹치지 않는 위치를 유지한다. 설명에서는 핵심 단어만 굵게 강조하고 일부 포인트에는 연노란색을 쓴다.
- 이후 장면은 반투명 흰색 가이드 카드와 기존 글자 크기를 유지한다. 왼쪽에는 제스처로 누르기 쉽게 간격을 둔 홈, 이전, 도움말 버튼이 있다. 도움말은 버튼과 오른쪽·아래쪽 여백에서도 열리고, 손이 멀어져도 표시 시간을 확보한 뒤 닫힌다.

## 후속 기획

초기 구상은 장소를 오가며 약 10초씩 걸리는 5가지 미션을 완료하는 흐름이다. 전체 배경에서 오브제를 고르면 해당 장소로 줌인하고, 미션을 끝낸 뒤 박수로 전체 배경에 돌아오는 방식이 제안됐다. 모든 미션을 완료하면 자신이 만든 별자리를 바라보고 근무 확인서를 받는다. 현재 도입부 이후의 장소, 미션 내용, 제스처와 엔딩 연출은 작업을 진행하며 확정한다.

## 실행과 이미지

- 시작 파일은 [starkeeper.html](starkeeper.html)이다. 웹캠을 포함한 동작을 확인할 때는 HTTPS로 제공되는 [GitHub Pages](https://okjrj.github.io/lyj-starkeeper/starkeeper.html) 또는 로컬 HTTP 서버의 localhost에서 연다.
- 화면과 스타일은 `starkeeper.html`, `styles.css`, 화면 전환과 손 인식은 `scene.js`에 있다. MediaPipe 모듈과 손 인식 모델은 브라우저에서 인터넷으로 불러온다.
- 아침 배경은 `image/S11/11-1-1.png`, 배경음은 `image/앞부분.mp4`의 도입부에서 가져왔다. 전시 실행 창에서는 타이틀이 열릴 때 음악이 시작된다. 자동 재생을 차단하는 일반 브라우저에서는 첫 클릭이나 키 입력으로 시작된다.
- [image](image/)에는 타이틀 원본, 방 원본과 파노라마, 창가 원본과 인물을 지운 버전, 후속 장면용으로 보관한 열린 창가 이미지가 있다. [assets](assets/)에는 타이틀 로고, 구름, 장갑 그래픽, 장면 프레임이 있다.
- [references](references/)에는 대화에 첨부했던 타이틀 배경 두 장, 게임 UI 배치 레퍼런스 두 장, 한글 타이틀 디자인 레퍼런스 두 장이 있다.

## Windows 전시 EXE 빌드

Chrome이 설치된 Windows 10/11에서 저장소 루트를 열고 다음 명령을 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\exhibition\build.ps1
```

생성된 `exhibition/dist/Starkeeper.exe` 하나를 전시 PC에 복사한다. 더블클릭하면 게임 파일과 영상이 임시 폴더에 풀리고 Chrome 전시 창이 열린다. 창에서 E를 누르거나 창을 닫으면 종료된다. 손 인식 모델을 처음 불러올 때는 인터넷 연결이 필요하다.
